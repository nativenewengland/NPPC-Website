# Batch 262 original sources

These are the unmodified National Archives image downloads used for 100 exact portrait crops and their available identifying reverses. `catalog-records.json` preserves the public catalog metadata, inmate identifiers and observed download URLs. The supplemental IWW roster was extracted without re-encoding from page 6 of the [October 2017 NARA newsletter](https://www.archives.gov/files/kansas-city/press/newsletter/2017-october.pdf#page=6). It corroborates names and inmate numbers, not exact release dates.

Crop coordinates, original and output hashes, source URLs, and rights are recorded in [the payload](../../fixes/batch262.json) and [credits](../CREDITS-batch262.md). These originals are review evidence; the deploy script copies only the 100 PNG portraits to public storage.
