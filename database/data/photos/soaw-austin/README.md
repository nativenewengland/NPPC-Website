# SOAW Austin chronology portraits

These portraits were downloaded on October 3, 2026 from the individual biographical entries in the [SOAW Austin Prisoners of Conscience chronology](https://www.soaw-austin.org/POC1983_2012.php). The filenames are preserved from the source site. The archive owner has stated that permission to use the source photographs has been obtained from the rights holders.

The images are small contemporary portrait thumbnails. They were visually reviewed before installation; none contained an embedded frame or blank border requiring a crop. HTML `border` attributes on the source page were presentation styling and are not part of the image pixels.
