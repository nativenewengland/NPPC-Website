# Original crop sources for batch 261

These files retain the exact downloaded bytes. Credits and rights are in [CREDITS-batch261.md](../CREDITS-batch261.md). Each cropped assignment in [batch261.json](../../fixes/batch261.json) records its original file, SHA-256, dimensions and Pillow crop box `[left, top, right, bottom]`, with exclusive right and bottom edges. To reproduce a crop, open that original with Pillow and save `image.crop(box)` as PNG without resizing or other pixel changes.

`swarthmore-1075-original.jpg` is the handwritten name key for `swarthmore-1076-original.jpg`; the payload records each selected subject’s number. The full group and key are retained for identity review, not assigned as individual portraits.
