# Batch326 archival portrait credits

Eight original historical photographs cropped for new profiles only. No replacement of an existing portrait. The 1912 and1915 published photographs are public domain in the United States by publication date. Photographer names are not supplied in the reproduced captions; do not invent them. The seven-defendant photograph is credited to The World. Reproduction/scanning source: ILGWU News-History, Fiftieth Anniversary Convention Issue (1950), hosted by the Marxists Internet Archive. The archive describes its edition as public domain and requests source credit; this file supplies it. The1950 page design is not republished as a new portrait.

Source pages and identifying captions were visually reviewed. The PDF's first embedded image on the relevant page contains the original photographic pixels. It was decoded and transposed90degrees counterclockwise to its page orientation, without resampling, then cropped using the boxes below (left,top,right,bottom; right and bottom excluded). All crops are lossless PNGs. No generated or redrawn faces.
