# Batch 263 source evidence

Original NARA front/reverse photographs, catalog metadata, the NARA IWW roster, unmodified embedded images extracted from Labor Defender PDFs, and the Bain photograph with Commons metadata. Labor Defender embedded scans are retained in their original orientation; payload rotations are counterclockwise right-angle transposes before cropping. Shared group images retain their identification captions. PDF page numbers are one-based.

Coordinates, hashes, credits and source links are recorded in [the payload](../../fixes/batch263.json) and [portrait credits](../CREDITS-batch263.md). Only the 100 finished PNG portraits are copied to public storage during deployment.
