# Confirmed prisoner duplicate merges, round two

Prepared October 4, 2026. This batch contains 39 pairs for which the two live profiles describe the same person. The merge command preserves the canonical slug, moves distinct cases, consolidates profile fields and removes the duplicate row.

## Deployment result

Run on the live database October 4, 2026. Post-run inspection found all 39 canonical slugs, no remaining duplicate slugs, and 10,357 total prisoner profiles. A second high-score name scan reduced the live candidate list from 27 pairs to eight; those eight remain unmerged because they are known relatives, already unresolved identities, or matches that still require individual research.

## Corrections made during consolidation

- Walter Fauntroy's arrest is set to November 21, 1984, with release the next morning.
- Henry Howe's false 1966–1968 custody span is replaced by his December 22, 1965 sentencing and early-April 1966 parole after about three months.
- Dora Kelly Lewis retains the documented October 13, 1862 birth and January 31, 1928 death dates.
- Howard Moore's death is corrected to June 9, 1993 and his release to November 24, 1920, the day before Thanksgiving.
- Marie Haydée Beltrán Torres's birth is corrected to June 27, 1955 and release to April 14, 2009.
- Benjamin Song's arrest is set to July 15, 2025, after the weeklong search, rather than the July 4 event date.
- Edward “Naed” Smith's six-month term ends on the source's October 6, 2006 release date; the unrelated November 2005 action date no longer creates a 321-day display.
- Grover McCorvey's event date is no longer treated as the start of a new custody term because he was already imprisoned when the rebellion occurred.
- Yvette Kelley's outcome now records acquittal on the RICO conspiracy, conviction on two weapons counts, and probation/community service.
