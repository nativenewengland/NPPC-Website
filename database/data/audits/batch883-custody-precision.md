# Month/year precision for separate custody stays

CustodyPeriods accepts ISO YYYY, YYYY-MM and YYYY-MM-DD endpoints. Exact intervals retain their existing union and day-count behavior. Partial intervals retain source precision, never populate exact day totals, and display a conservative estimated day range based on independently unioned minimum/maximum intervals. Overlaps and gaps are handled in both bounds. Calendar-year charts continue to use the separate periods.
