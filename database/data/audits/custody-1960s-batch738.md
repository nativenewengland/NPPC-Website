# Batch 738: Mabel Williams return from exile

Correct return month from September to August 1969. September 12 contemporary report says Mabel returned a month earlier; appellate account independently places her arrival four weeks before early September. Exact day is unknown and month precision remains unchanged. No incarceration is asserted.
